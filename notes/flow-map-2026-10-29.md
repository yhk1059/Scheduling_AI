# 사용자 흐름 × 화면 지도 (as-is, 2026-10-29)

실제 수간호사의 사용 주기(PRD 저니) 순서로, 지금 앱에서 각 단계가 어느 화면에 있는지 정리한다. 판단은 맨 아래 "관찰"에만 둔다.

## 1. 사용 주기 → 지금 화면

| # | 단계 | 사용자가 하는 일 | 빈도 | 지금 화면 (위치) | 들어가는 방법 |

## 2. 화면 → 담긴 단계

| 화면 | 경로 / 진입 | 담긴 단계 | 주요 행동(Primary) |
|---|---|---|---|
| 랜딩 | `/` | 0 | [샘플로 체험하기] [내 병동으로 시작하기] |
| 샘플 데모 | `/demo` | 0 | [내 병동으로 시작하기] |
| 시작 화면 | `/app` (병동 없을 때, 게스트의 [시작 화면]) | 0 | [이어서 하기] / [내 병동으로 시작하기] |
| 병동 홈 | `/app` 탭 [근무표] | 3, 8(입구), 10 | [○월 근무표 만들기] 또는 [이어서 하기] |
| 병동 설정 › 명단·필요 인원 | 탭 [병동 설정] | 1 | 명단 적용 |
| 병동 설정 › 병동 규칙 | 탭 [병동 설정] › 두 번째 탭 | 2 | 규칙 만들기 → [적용] |
| 기간 작업 › ① 준비 | 근무표 열기 | 4, 9(배너) | [다음] |
| 기간 작업 › ② 요청 | 스테퍼 | 5 | 요청 만들기 → [적용] |
| 기간 작업 › ③ 근무표 | 스테퍼 | 6, 6-a, 7, 8, 9(배너) | [근무표 만들기] / [확정] / [요청 만들기] / [다시 확정] |

## 3. 관찰
- **③ 근무표 한 화면에 단계 다섯 개(6, 6-a, 7, 8, 9)가 겹친다.** 작성(만들기·조정·확정)과 운영(변경·다시 확정)은 시점도 마음가짐도 다른데, 상태(작성 중 / 확정 / 운영 중)에 따라 같은 화면이 다르게 바뀐다.
- **"말로 규칙 적기"(2)가 병동 설정의 두 번째 탭에 있다.** 제품의 핵심인데 진입이 가장 깊다. 같은 입력 방식이 ② 요청(5), 운영 중 변경(8)에도 따로 있다.
- **처음 1회 단계(1, 2)와 기간마다 단계(3~7)의 경계가 화면에 드러나지 않는다.** 처음 쓰는 사람은 병동 설정 → 병동 홈 → 기간 작업으로 화면을 세 번 바꾼다.
- **운영 중 변경(8)의 입구가 홈의 [열기] 하나뿐이다.** "병가가 생겼다"는 가장 급한 상황인데 근무표를 열고 아래로 내려가야 입력칸이 나온다.
- **① 준비(4)는 대부분 확인만 한다.** 날짜·명단·이월이 자동으로 채워져서, 바꿀 게 없으면 [다음]만 누른다.
