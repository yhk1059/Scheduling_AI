# UI 디자인 가이드

시안: [간호사 근무표 디자인](https://claude.ai/artifact/JkfNaqQHwVvjVs2WK669fZ) (디자인 시스템 · ④ 근무표 · 랜딩 페이지). 라이트 테마, 데스크톱(1280px 이상) 전용.
"화면 구조"와 "반복 사용 컴포넌트"는 시안 이후에 텍스트 규칙으로 추가했다. 시각 규칙은 아래 색상·컴포넌트를 그대로 따른다.

## 디자인 원칙
1. 엑셀 옆에 둬도 어색하지 않은 업무 도구다. 정보 밀도가 먼저다. 장식, 일러스트, 히어로 영역을 두지 않는다. 표는 표답게 촘촘하게.
2. 결정은 사람이 한다. LLM이 해석한 결과는 항상 카드로 제안되고, [적용]이나 [수락]을 누르기 전에는 근무표에 반영되지 않는다.
3. 색은 근무 코드와 상태에만 쓴다. 나머지 화면은 무채색이다. 색이 보이면 의미가 있다: D/E/N/O, 성공·오류·주의, 변경된 칸.
4. 다음에 할 일이 한눈에 보인다. 화면마다 지금 할 일 하나를 Primary로 두고, 자주 쓰지 않는 정보(비활성 간호사, 해석 결과 원문)는 접어 둔다.
5. 되돌릴 수 있는 동작은 묻지 않고 바로 하고, 되돌리는 버튼을 둔다. 되돌릴 수 없는 동작만 확인을 받는다.

## 화면 구조
```
/app
├── 시작 화면   로그인하지 않았고 병동이 없을 때만
├── 병동 홈     기본 화면
├── 병동 설정   탭 2개: [명단·필요 인원] [병동 규칙]
└── 기간 작업   스테퍼 3단계: ① 준비 → ② 요청 → ③ 근무표
```
- **이동**
  - 상단 바 아래에 [홈] [병동 설정] Text 탭을 둔다. 현재 탭은 `font-semibold text-[#1B1B18]`과 `aria-current="page"`로 표시한다.
  - 기간 작업 화면에서는 제목 위의 "← 홈" Text 링크로 돌아간다.
- **처음 쓰는 경우**: 병동 설정(명단·필요 인원 → 병동 규칙) → [첫 기간 만들기] 순서로 안내한다. 병동이 준비된 뒤에는 항상 병동 홈에서 시작한다.
- **시작 화면**: [샘플로 체험하기], [내 병동으로 시작하기], [Google로 로그인]. 브라우저에 게스트 입력이 있으면 [이어서 하기]를 더한다.

### 병동 홈
위에서부터 다음 순서로 놓는다.
1. **운영 중 기간 카드**: 날짜 범위(mono), `운영 중` 배지, 마지막 확정 시각, [열기] Secondary
2. **다음 기간 카드**: 상태에 따라 버튼이 하나다.
   - 없음: [다음 기간 만들기] Primary. 홈의 유일한 Primary다.
   - 초안: [이어서 작성] Secondary
   - 확정: [열기] Secondary
3. **최근 기간 표**: 기간, 상태 배지, 확정 시각. 행을 누르면 그 기간 작업 화면으로 간다.
4. **병동 요약 한 줄**: "활성 15명 (비활성 1명) · 병동 규칙 6개" + [병동 설정] Text

### 기간 작업
- **제목**: 날짜 범위(`font-mono text-[22px] font-semibold`) + 기간 상태 배지
- **스테퍼**: 제목 아래에 둔다. 이미 지난 단계는 언제든 눌러 돌아갈 수 있다.
  - **① 준비**
    - 날짜 범위(읽기 전용)
    - 공휴일 체크
    - 명단 점검: 지난 기간 이후 바뀐 사람 요약 + [병동 설정] Text
    - 이월 근무 표
  - **② 요청**: 자연어 입력 바 + 요청 카드
  - **③ 근무표**: 생성, 해 없음 패널, 근무표, 요약 지표, 통계 표, 확정, 운영 중 변경 입력 바

### 병동 설정
- 탭 [명단·필요 인원]: 맨 위에 "기본" 영역(병동 이름, 기간 단위 select)을 두고, 그 아래 명단 표와 필요 인원 폼을 둔다.
- 탭 [병동 규칙]: 자연어 입력 바 + 규칙 카드
- 기간 단위를 바꾸면 "다음에 만드는 기간부터 적용돼요. 최소 오프 일수 같은 규칙 값을 다시 확인하세요"를 주의 배너로 보여 준다.

### 근무 코드
글자를 항상 함께 표시한다. 색만으로 구분하지 않고, 밝기도 O > D > E > N 순으로 다르다.

| 코드 | 값 |
|------|------|
| D 데이 | `bg-[#FFF1C2] text-[#5C4300]` |
| E 이브닝 | `bg-[#F9CFAE] text-[#6E2A04]` |
| N 나이트 | `bg-[#263248] text-white` |
| O 오프 | `bg-white text-[#6B6B63] font-normal border border-[#E2E2DC]` (주말·공휴일이면 `bg-[#F1EEE6]`) |

## 컴포넌트
모서리는 크기에 따라 다르게 한다: 셀 `rounded-xs`(2px) · 배지 `rounded-sm`(4px) · 버튼·입력 `rounded-md`(6px) · 카드 `rounded-lg`(8px).

### 카드
```
rounded-lg bg-white border border-[#E2E2DC] px-[18px] py-4
```
- 적용 대기 카드: 테두리만 `border-[#C9C9C1]`로 한 단계 진하게
- 해 없음 패널: `border-[#E8B4AE]`
- 카드에 왼쪽 굵은 테두리 강조나 그림자를 넣지 않는다

### 버튼
```
공통:      inline-flex items-center gap-2 h-10 px-4 rounded-md text-sm font-medium transition-colors duration-[120ms]
Primary:   bg-[#155E75] text-white border border-[#155E75] hover:bg-[#0E4A5C]
Secondary: bg-white text-[#1B1B18] border border-[#C9C9C1] hover:bg-[#EFEFEB]
Text:      px-2 text-[#3D3D38] hover:bg-[#EFEFEB] hover:text-[#1B1B18]
Danger:    px-2 text-[#B42318]  (삭제 등)
Disabled:  bg-[#EFEFEB] text-[#9A9A91] border border-[#E2E2DC] cursor-not-allowed
카드 안:   h-8 text-[13px]
랜딩:      h-11 text-[15px] px-[18px]
```
한 영역에 Primary는 하나만 둔다.
- **배치**: Primary는 영역의 오른쪽 끝에 둔다. Danger는 Primary와 떨어뜨려 왼쪽에 두거나 메뉴 안에 넣는다. 바로 옆에 붙이지 않는다.
- **레이블**: 눌렀을 때 일어나는 일을 동사로 쓴다("생성", "적용", "다음 기간 만들기"). "확인", "OK"처럼 결과를 알 수 없는 레이블은 쓰지 않는다.

### 입력 필드
```
h-10 rounded-md bg-white border border-[#8A8A80] px-3 text-sm text-[#1B1B18] placeholder:text-[#707068]
focus:outline-2 focus:outline-[#155E75] focus:-outline-offset-1 focus:border-[#155E75]
```
- 레이블은 항상 `<label>`로 위에 둔다: `text-xs font-medium text-[#3D3D38]`
- 자연어 입력 바(규칙·요청·월중 변경 공통): 입력 `flex-1` + 오른쪽 Primary 버튼, `gap-2`. placeholder는 "예: 나이트 다음 날은 무조건 쉬게"처럼 실제 말투 예시

### 배지
```
inline-flex items-center h-[22px] px-2 rounded-sm text-xs font-semibold
hard:      bg-[#1B1B18] text-white
soft:      bg-white text-[#3D3D38] border border-[#C9C9C1]
검증됨:    bg-[#E6F2EA] text-[#1E6B3F]
적용 대기: bg-[#FDF0DC] text-[#7A4506]
해 없음:   bg-[#FBE9E7] text-[#9F1F14]
초안:      soft와 같음
확정:      검증됨과 같음
운영 중:   bg-[#E3F0F3] text-[#155E75]
이번 기간 꺼짐: 적용 대기와 같음
비활성:    bg-[#EFEFEB] text-[#66665E]
```

### hard/soft 토글
```
컨테이너: inline-flex rounded-md border border-[#C9C9C1] overflow-hidden
버튼:     h-7 px-3 text-xs font-medium bg-white text-[#66665E]
선택됨:   aria-pressed="true" → bg-[#1B1B18] text-white
```

### 규칙·요청 카드
위에서부터 템플릿 이름(`text-[13px] font-semibold`) + hard/soft 토글, 원문 인용(“…”, `text-sm text-[#1B1B18]`), 해석 결과(`font-mono text-xs text-[#66665E] bg-[#F6F6F3] rounded-sm px-2.5 py-2`), 상태 배지 + 버튼(적용됨이면 수정·삭제, 대기면 삭제·적용).

### 제안 카드
제목 + `검증됨` 배지, 설명 한 줄, 재풀이 결과(`font-mono text-xs text-[#66665E]`, 예: "재풀이 결과 · 해 있음 · 희망 반영 14/16"), 오른쪽 아래 [무시] Text + [수락] Primary. 재풀이로 검증되지 않은 제안은 보여주지 않는다.

### 스테퍼
- 위치: 기간 작업 화면의 제목 아래. 상단 바에는 두지 않는다.
- 이미 지난 단계는 `<button>`으로 눌러 돌아갈 수 있다. 아직 오지 않은 단계는 비활성이다.
- 완료: `size-[22px] rounded-full bg-[#E3F0F3] text-[#155E75]` 안에 체크 SVG, 레이블 `text-[#3D3D38]`
- 현재: `bg-[#155E75] text-white` 숫자(mono), 레이블 `font-semibold text-[#1B1B18]`, `aria-current="step"`
- 단계 사이: `w-6 h-px bg-[#C9C9C1]`

### 근무 셀
```
relative w-[30px] h-7 rounded-xs inline-flex items-center justify-center font-mono text-[13px] font-semibold border border-transparent
+ 근무 코드 색상
고정:      오른쪽 위 자물쇠 SVG (absolute top-px right-px size-[9px])
변경됨:    shadow-[inset_0_0_0_2px_#D97706]
선택·편집: outline-2 outline-[#155E75] outline-offset-1
```
- 셀은 `<button>`으로 만들고 `aria-label="{이름} {M}월 {D}일 {코드}"`. 기간이 월 경계를 넘을 수 있으므로 월을 날짜마다 계산한다.
- 행 그리드: `grid-cols-[150px_44px_repeat(N,30px)_repeat(4,34px)_repeat(2,44px)] gap-x-0.5`, N은 기간 길이(7~31), 행 간격 2px
- 표 하단에 날짜별 D/E/N 합계 행, 오른쪽에 개인별 D/E/N/O 합계 열과 누적 부담 열 2개(최근 4주 N, 주말)
- 날짜 헤더가 달의 1일이면 `M/1`로 월을 함께 쓴다.
- **지난 날짜**: 운영 중인 기간에서 오늘 이전 칸은 고정 자물쇠를 표시하고 눌러도 편집되지 않는다. 오늘 열 머리에는 `border-b-2 border-[#155E75]` 밑줄을 긋는다.

### 반복 사용 컴포넌트
- **꺼진 규칙·요청 카드**
  - 원문과 해석 결과를 보조 색(`text-[#66665E]`)으로 낮춘다. 읽을 수 있어야 하므로 비활성 컨트롤 색은 쓰지 않는다.
  - `이번 기간 꺼짐` 배지와 [다시 켜기] Text 버튼을 둔다.
  - 병동 규칙 탭에서는 꺼짐이 보이지 않는다. 꺼짐은 그 기간에만 있다.
- **비활성 간호사**
  - 명단 표에서 이름을 `text-[#66665E]`로 하고 `비활성` 배지를 붙인다.
  - 기본으로 접어 두고 "비활성 1명 보기" Text 버튼으로 펼친다.
  - 행의 동작은 [삭제] 대신 [비활성으로] / [다시 활성으로]다.
- **이월 근무 표**
  - 근무 셀 그리드를 재사용한다. 열은 지난 기간 마지막 날들이고, 표 위에 "지난 기간 확정본에서 가져왔어요" 보조 텍스트를 둔다.
  - 셀은 `<div>`로 만들고 편집하지 않는다.
  - 첫 기간처럼 지난 확정본이 없으면 기존 붙여넣기 입력을 보여 준다.
- **누적 부담 근거**
  - 통계 표의 누적 부담 열은 mono 숫자다.
  - 요약 지표 아래에 한 줄로 "최근 4주 나이트가 많았던 3명은 이번 기간 나이트를 줄였어요"처럼 근거를 쓴다. 숫자가 없으면 쓰지 않는다.
- **배너**: 이월 변경, 게스트 저장 안내, 저장 실패, 기간 단위 변경은 모두 기존 주의 배너(`bg-[#FDF0DC] border-[#F1D3A8] text-[#7A4506]`) 하나로 쓴다. 배너에 버튼은 최대 하나다.
- **저장 상태**: 상단 바 오른쪽, 계정 왼쪽에 `text-xs text-[#66665E]`로 둔다.
  - 게스트: "이 브라우저에만 저장"
  - 로그인: "저장됨 14:32"(mono 시각)
  - 실패: `text-[#B42318]` "저장 실패" + [다시 시도] Text
- **계정**
  - 로그인 전: [Google로 로그인] Secondary
  - 로그인 후: 이메일(`text-xs`) + 메뉴 버튼. 메뉴 항목은 [로그아웃], [내 병동 데이터 삭제] Danger
- **대화상자**
  - 로그인 요구, 샘플 저장 여부, 데이터 삭제 확인에만 쓴다.
  - 배경 `fixed inset-0 bg-[#1B1B18]/40`, 본문은 카드 스타일 `w-full max-w-[440px]`. blur와 그림자를 쓰지 않는다.
  - 제목(섹션 제목 스타일), 본문 한두 줄, 오른쪽 아래 버튼. Primary는 하나다.
  - 데이터 삭제는 2단계다. 첫 대화상자에서 [계속], 두 번째에서 병동 이름을 입력하고 [삭제](Danger 스타일을 Primary 자리에 둔다).
  - `role="dialog"`, `aria-modal="true"`, Esc로 닫고, 열릴 때 첫 버튼에 포커스를 둔다.

### 요약 지표
카드 안 가로 배치, 칸마다 `px-5 py-3.5 border-r border-[#E2E2DC]`. 레이블 `text-xs font-medium text-[#66665E]`, 값 `font-mono text-xl font-semibold text-[#1B1B18]`. soft 위반 값만 `text-[#A15C07]`.

## 상호작용 상태
버튼, 탭, 근무 셀, 토글은 아래 상태를 모두 가진다. 같은 종류의 컨트롤은 화면이 달라도 똑같이 동작한다.

| 상태 | 규칙 |
|---|---|
| 기본 | 버튼은 버튼답게 보인다. 레이블만 봐도 결과를 알 수 있다 |
| hover | 색만 바꾼다(`transition-colors duration-[120ms]`) |
| 눌림 | `active:` 상태에서 hover보다 한 단계 진하게 한다(Primary `active:bg-[#0B3F4E]`, Secondary·Text `active:bg-[#E2E2DC]`) |
| 포커스 | 키보드 포커스에만 `focus-visible:outline-2 focus-visible:outline-[#155E75] focus-visible:outline-offset-2`. 포커스 표시를 없애지 않는다 |
| 비활성 | 숨기지 않고 비활성 스타일로 둔다. **왜 못 누르는지** 버튼 옆이나 아래에 한 줄로 쓴다. 예: "필요 인원을 입력하면 다음으로 넘어갈 수 있어요" |
| 진행 중 | 레이블을 "푸는 중…", "해석 중…", "저장 중…"으로 바꾸고 스피너 하나만 둔다. 진행 중에는 버튼을 비활성으로 해서 두 번 보내지 않게 한다 |
| 성공 | 결과가 놓일 자리에 보여 준다(카드 배지가 `적용됨`으로 바뀜, 근무표가 갱신됨, 저장 상태가 "저장됨 14:32"로 바뀜). 토스트는 쓰지 않는다 |
| 실패 | 버튼을 다시 누를 수 있는 상태로 되돌리고, 바로 아래에 무엇이 잘못됐고 무엇을 하면 되는지 쓴다 |
| 선택됨 | 채운 스타일(`bg-[#1B1B18] text-white`)과 `aria-pressed="true"`, 탭은 `aria-current="page"` |

## 피드백과 오류
- **결과는 그 자리에서**: 동작의 결과는 누른 버튼 가까이에 보여 준다. 화면 위쪽 전역 알림으로 보내지 않는다. 예외는 상단 바의 저장 상태 하나다.
- **기다림**: 2초를 넘을 수 있는 작업(생성, 해석, 제안 검증)은 진행 중 상태를 보여 준다. 진행률을 알 수 없으므로 진행 막대는 쓰지 않는다.
- **오류 문구**: "무엇이 일어났는지 + 무엇을 하면 되는지" 두 부분으로 쓴다. 예: "해석하지 못했어요. 날짜를 '15~17일'처럼 다시 적어 주세요." 오류 코드나 영어 원문을 그대로 보여 주지 않는다.
- **되돌릴 수 있는 동작은 즉시**: 카드 삭제, 이번 기간만 끄기, 비활성으로 바꾸기는 확인 없이 바로 하고, 그 자리에 되돌리기(다시 켜기, 다시 활성으로)를 둔다.
- **되돌릴 수 없는 동작만 확인**: 내 병동 데이터 삭제, 게스트 입력을 지우고 새로 시작하기는 대화상자로 확인한다. 대화상자의 버튼은 두 개까지다.
- **예방**: 틀릴 수 있는 입력은 고르게 한다(기간 단위 select, 공휴일 달력, 명단 열 매핑). 자유 입력은 자연어 입력 바뿐이고, 그 결과는 항상 카드로 확인받는다.

## 문구
- **말투**: 해요체로 짧게 쓴다. 한 문장에 한 가지만 말한다.
- **같은 것은 같은 말로**: 화면마다 용어를 바꾸지 않는다.

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| 기간, 이번 기간, 다음 기간 | 이달, 이번 달 | 병동의 기간 단위 하나(1주~달력 월) |
| 병동 규칙 | 설정, 제약 | 기간이 바뀌어도 유지되는 규칙 |
| 요청 | 이달 요청, 희망 | 이번 기간에만 적용되는 휴가·희망·기피 |
| 이월 근무 | 전월 근무 | 지난 기간 마지막 며칠의 근무 |
| 초안 / 확정 | 저장, 완료 | 기간의 상태 |
| 적용 | 추가, 저장 | 규칙·요청 카드를 반영하는 것 |
| 수락 | 적용 | 검증된 완화 제안을 반영하는 것 |
| 비활성 | 삭제, 퇴사 | 명단에서 새 기간 생성에서만 빠진 상태 |

- **hard/soft**: 배지와 토글에는 `hard`/`soft`를 쓰고, 처음 보는 사람을 위해 토글에 `title`로 "반드시 지킴" / "가능하면 지킴"을 붙인다.
- **빈 상태**: 비어 있는 영역에는 무엇을 하면 채워지는지 한 줄과 그 동작 버튼을 둔다. 예: 최근 기간 표가 비면 "아직 확정한 기간이 없어요" + [첫 기간 만들기].

## 접근성
- **대비** (WCAG 2.2 AA): 본문 텍스트 4.5:1, 큰 텍스트와 컨트롤 경계 3:1 이상. 이 가이드의 색 조합을 계산한 결과는 아래와 같다.
  - 통과: 주 텍스트·본문·보조(`#66665E` 5.8:1), 강조(`#155E75` 7.3:1), 시맨틱 배지 전부(5.6~7.0:1), 근무 코드 전부(4.6~12.9:1)
  - 정보 텍스트에 쓰지 않음: 비활성 컨트롤 색 `#9A9A91`(2.8:1)
  - 이번에 바꿈: placeholder `#8A8A80` → `#707068`(5.0:1), 입력 테두리 `#C9C9C1`(1.7:1) → `#8A8A80`(3.5:1)
- **색만으로 구분하지 않는다**: 근무 코드는 글자, 상태는 배지 글자, 변경된 칸은 테두리, 고정은 자물쇠로 함께 표시한다.
- **키보드**
  - 모든 동작은 Tab과 Enter/Space로 할 수 있다.
  - 스테퍼 단계를 옮기면 새 단계의 제목(`h2`, `tabIndex={-1}`)으로 포커스를 옮긴다.
  - 대화상자를 닫으면 연 버튼으로 포커스를 되돌린다.
- **상태 알림**: 진행 중, 결과, 오류 문구는 `role="status"`(오류는 `role="alert"`) 안에 두어 스크린 리더가 읽게 한다.
- **레이블**: 아이콘만 있는 버튼은 `aria-label`, 입력은 `<label>`을 쓴다. placeholder를 레이블 대신 쓰지 않는다.

## 레이아웃
- 전체 너비: `max-w-[1360px] mx-auto px-8`
- 정렬: 좌측 정렬 기본. 중앙 정렬 히어로 금지
- 간격: 카드 사이 `gap-4`~`gap-5`, 앱 화면 섹션 사이 `gap-5`, 카드 안 `gap-2.5`~`gap-3.5`
- 묶음: 관련된 입력과 버튼은 같은 카드 안에 붙여 둔다. 서로 다른 일은 카드를 나눈다. 카드 안의 간격은 카드 사이 간격보다 항상 좁다
- 위계: 화면마다 페이지 제목은 하나다. 화면을 위에서부터 읽으면 "지금 상태 → 할 일 → 결과" 순서가 되게 놓는다
- 앱 상단 바: `bg-white border-b border-[#E2E2DC]`, 왼쪽 앱 이름 + 병동 이름·기간 단위, 오른쪽 저장 상태 + 계정. 스테퍼는 두지 않는다
- 탭 줄: 상단 바 바로 아래 `bg-white border-b border-[#E2E2DC]`, [홈] [병동 설정]. 시작 화면에서는 숨긴다
- 근무표·통계 표는 `overflow-x-auto` 상자 안에 둔다. 표를 줄이거나 셀을 30px보다 작게 만들지 않는다
- 랜딩 페이지: 섹션 `py-[72px] border-t border-[#E2E2DC]`, 첫 화면은 좌측 텍스트 + 우측 실제 제품 화면 조각(규칙 카드, 근무표 일부). 장식 이미지나 근거 없는 수치·후기를 넣지 않는다

## 아이콘
- SVG 인라인, `stroke="currentColor"`, strokeWidth 1.5~1.8, 크기 12~14px
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다 (스테퍼 단계 원은 예외)

- 장식용 SVG는 `aria-hidden="true"`, 아이콘만 있는 버튼은 `aria-label`
