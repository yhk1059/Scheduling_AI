# UI 디자인 가이드

시안: [간호사 근무표 디자인](https://claude.ai/artifact/JkfNaqQHwVvjVs2WK669fZ) (디자인 시스템 · ④ 근무표 · 랜딩 페이지). 라이트 테마, 데스크톱(1280px 이상) 전용.
"화면 구조"와 "반복 사용 컴포넌트"는 시안 이후에 텍스트 규칙으로 추가했다. 시각 규칙은 아래 색상·컴포넌트를 그대로 따른다.

## 디자인 원칙
1. 엑셀 옆에 둬도 어색하지 않은 업무 도구다. 정보 밀도가 먼저다. 장식, 일러스트, 히어로 영역을 두지 않는다. 표는 표답게 촘촘하게.
2. 결정은 사람이 한다. LLM이 해석한 결과는 항상 카드로 제안되고, [적용]이나 [수락]을 누르기 전에는 근무표에 반영되지 않는다.
3. 색은 근무 코드와 상태에만 쓴다. 나머지 화면은 무채색이다. 색이 보이면 의미가 있다: D/E/N/O, 성공·오류·주의, 변경된 칸.
4. 다음에 할 일이 한눈에 보인다. 화면마다 지금 할 일 하나를 Primary로 두고, 자주 쓰지 않는 정보(제외된 간호사, 해석 결과 원문)는 접어 둔다.
5. 되돌릴 수 있는 동작은 묻지 않고 바로 하고, 되돌리는 버튼을 둔다. 되돌릴 수 없는 동작만 확인을 받는다.

## 화면 구조
```
/app
├── 시작 화면     병동이 없을 때, 또는 게스트가 [시작 화면]을 눌렀을 때
├── 처음 설정     근무표를 한 번도 만들지 않은 병동. 스테퍼 ① 병동·명단 → ② 필요 인원 → ③ 병동 규칙
├── 병동 홈       기본 화면 (탭 이름은 [근무표])
├── 병동 설정     탭 2개: [명단·필요 인원] [병동 규칙]. 처음 설정을 마친 뒤 고칠 때 쓴다
├── 근무표 작성   작성 중인 근무표. 스테퍼 ① 요청 → ② 근무표, 끝 버튼 [확정]
└── 확정 근무표   확정한 근무표(운영 중·시작 전·지난). 스테퍼 없음
```
- **이동**
  - 상단 바 아래에 [근무표] [병동 설정] Text 탭을 둔다. 게스트면 오른쪽 끝에 [시작 화면] Text를 둔다. 현재 탭은 `font-semibold text-[#1B1B18]`과 `aria-current="page"`로 표시한다.
  - 근무표 작성·확정 근무표 화면에서는 제목 위의 "← 근무표 목록" Text 링크로 돌아간다.
  - 처음 설정 중에는 탭 줄의 [근무표] [병동 설정]을 숨긴다(게스트의 [시작 화면]은 둔다).
  - 근무표를 열면 상태로 화면이 정해진다: 작성 중 → 근무표 작성(근무표를 만들었으면 ②, 아니면 ①), 확정 → 확정 근무표.
- **처음 쓰는 경우**: 근무표를 한 번도 만들지 않은 병동에 들어오면 처음 설정의 아직 끝나지 않은 첫 단계를 연다(명단 없음 → ①, 필요 인원 없음 → ②, 그 밖 → ③). 첫 근무표를 만든 뒤에는 저장된 화면에서 시작한다.
- **시작 화면**: 카드 두 개 [샘플로 체험하기](샘플 데모 `/demo`로 가는 링크), [내 병동으로 시작하기]. 게스트 입력이 있으면 시작 화면을 건너뛰고 바로 들어간다. 탭 줄의 [시작 화면]으로 열었을 때는 [이어서 하기]를 더해 돌아갈 수 있게 한다. 로그인은 상단 바의 [Google로 로그인] 하나만 두고, 카드 아래에 "로그인하면 다른 기기에서도 이어서 쓸 수 있어요" 한 줄과 [개인정보처리방침] Text 링크를 둔다.
- **근무표 이름**: 화면에서는 기간을 "근무표"로 부르고 날짜로 이름을 붙인다. 달력 월이면 "11월 근무표", 주 단위면 "11/2~11/15 근무표". 제목과 카드에는 이 이름을 쓰고, 정확한 날짜 범위(mono)는 그 옆에 보조로 둔다.

### 병동 홈
홈은 "지금 할 일"을 먼저 보여 준다. 위에서부터 다음 순서로 놓는다.
1. **제목 줄**: 병동 이름(페이지 제목) + 오른쪽에 병동 요약 한 줄 "간호사 15명 · 병동 규칙 6개 · 한 달 단위" + [병동 설정] Text. 병동 규칙 수에는 필요 인원을 넣지 않는다(모든 화면에서 같게 센다).
2. **운영 중 근무표 카드**(오늘이 속한 확정 근무표가 있을 때만): "10월 근무표", `운영 중` 배지, "마지막 확정 10/28 14:32", [변경 입력] Secondary. 누르면 확정 근무표 화면을 열고 변경 입력 바에 포커스를 둔다
3. **지금 할 일 카드**(다음 근무표): 카드 안에 진행 단계를 한 줄로 보여 주고(① 요청 → ② 근무표 → 확정, 끝난 단계는 체크), 상태를 문장 하나로 쓴다. 버튼은 하나이고 홈의 유일한 Primary다.
   | 상태 | 문장 | 버튼 |
   |---|---|---|
   | 없음 | "12월 근무표를 만들 차례예요" | [12월 근무표 만들기] |
   | 작성 중, 생성 전 | "요청 2개를 넣었어요. 아직 근무표를 만들지 않았어요" | [이어서 하기] |
   | 작성 중, 생성 후 | "근무표를 만들었어요. 확인하고 확정하세요" | [근무표 확인하기] |
   | 확정 | "확정했어요 · 10/28 14:32" | [열기] (Secondary, 이때는 다음 근무표 만들기가 Primary) |
4. **지난 근무표 표**: 확정한 지난 근무표만 둔다(근무표 이름, 확정 시각). 행을 누르면 그 근무표의 확정 근무표 화면(보기 전용)으로 간다. 비어 있으면 표 대신 "확정한 근무표가 여기에 쌓여요" 한 줄만 둔다. 지금 할 일 카드와 같은 근무표를 다시 보여 주지 않는다.

### 처음 설정
- **제목**: "처음 설정"(페이지 제목) + 스테퍼 ① 병동·명단 → ② 필요 인원 → ③ 병동 규칙
- 단계마다 오른쪽 아래에 Primary 하나, 왼쪽에 [이전] Secondary(①에는 없음)
  | 단계 | 담는 것 | Primary | 누를 수 없을 때 한 줄 |
  |---|---|---|---|
  | ① 병동·명단 | 병동 설정 "기본" 영역(병동 이름, 근무표 주기), 명단 표(맨 아래 입력 줄로 한 명씩 추가) | [다음] | "명단에 간호사를 1명 이상 넣으면 다음으로 넘어갈 수 있어요" |
  | ② 필요 인원 | 근무조별 필요 인원 폼(아래 "필요 인원 폼") | [다음] | "필요 인원을 모두 입력하면 다음으로 넘어갈 수 있어요" |
  | ③ 병동 규칙 | 병동 규칙 탭과 같은 자연어 입력 바, 예시 Text 버튼, 규칙 카드, [모두 적용] | [첫 근무표 만들기] | 없음(항상 누를 수 있다) |
- ③에서 적용한 규칙이 0개면 Primary 옆에 "규칙 없이 만들면 필요 인원만 지켜요" 한 줄. 적용 대기 카드가 남아 있으면 "적용하지 않은 규칙 2개는 빠져요" 한 줄
- 각 단계의 입력은 병동 설정과 같은 컴포넌트를 쓴다. 바꾼 내용은 바로 저장된다

### 근무표 작성
- **제목**: 근무표 이름("11월 근무표", 페이지 제목) + 날짜 범위(mono, 보조) + `작성 중` 배지
- **스테퍼**: 제목 아래에 둔다. 이미 지난 단계는 언제든 눌러 돌아갈 수 있다.
  - **① 요청**
    - 맨 위에 준비 요약 카드 한 줄: 날짜 범위(mono) · 공휴일 n일(없으면 "공휴일 없음") · 간호사 n명 · 지난 근무("지난 근무표에서 이어져요" / "지난 근무 없음") + [바꾸기] Text(`aria-expanded`)
    - 펼치면 날짜(읽기 전용), 공휴일 체크, 명단 확인, 지난 근무 마지막 며칠을 둔다.
      - 명단 확인: "지난 근무표 이후 2명 추가 · 1명 제외"처럼 바뀐 사람 요약. 바뀐 사람이 없으면 "지난 근무표와 명단이 같아요". + [병동 설정] Text
      - 지난 근무 마지막 며칠: 지난 확정 근무표가 있으면 읽기 전용 표. 없으면(첫 근무표) 접힌 "지난 근무 입력하기 (선택)" Text 버튼만 두고, 펼치면 붙여넣기 입력과 예시 한 줄을 보여 준다.
    - 저절로 펼치는 경우: 명단이 지난 확정 근무표와 다를 때, 지난 근무표가 바뀌어 이어지는 근무가 달라졌을 때(배너와 함께). 그 밖에는 접어 둔다.
    - 그 아래 자연어 입력 바 + 요청 카드. 적용 대기 카드가 2개 이상이면 카드 목록 위에 [모두 적용] Secondary를 둔다.
    - 이 근무표에 적용되는 병동 규칙(접힌 목록)
    - 오른쪽 아래 [다음] Primary
  - **② 근무표**: 근무표 만들기, 해 없음 패널, 근무표, 요약 지표, 통계 표. 지난 근무표가 바뀌었으면 위에 지난 근무 변경 배너 + [다시 만들기]. 왼쪽 아래 [이전] Secondary
- **② 근무표의 버튼**: 지금 할 일 하나만 Primary다.
  | 상태 | Primary | 그 밖 |
  |---|---|---|
  | 만들기 전 | [근무표 만들기] | 설명 한 줄 "적용한 규칙과 요청으로 근무표를 만들어요"만 둔다. 칸 고정 안내는 근무표가 생긴 뒤에 보여 준다 |
  | 만든 뒤 | [확정] | [다시 만들기] Secondary, [CSV 받기] Text |
- [확정]을 누르면 확정 근무표 화면으로 옮겨 간다.

### 확정 근무표
- **제목**: 근무표 이름(페이지 제목) + 날짜 범위(mono, 보조) + `운영 중` 또는 `확정` 배지 + 오른쪽에 "마지막 확정 10/28 14:32"
- 스테퍼를 두지 않는다. 확정한 뒤에는 요청 단계로 돌아가지 않고, 늦게 온 요청·병가·휴가는 모두 변경 입력으로 넣는다(시작 전에 확정한 근무표도 같다).
- 위에서부터: 배너(게스트 저장 안내 + [Google로 로그인], 지난 근무 변경 + [다시 만들기]: 최소 변경으로 다시 만들고 [다시 확정]을 기다린다) → 변경 입력 카드("변경 입력" 제목, 설명 한 줄 "확정한 뒤 생긴 병가·휴가를 적으면, 확정 근무표에서 최소한으로 바꿔 다시 만들어요", 자연어 입력 바) → 변경 카드 → 바뀐 칸 요약("1명, 3칸 변경 · 주황 테두리 칸이 바뀐 곳이에요") → 요약 지표 → 근무표 → 통계 표
- 홈 운영 중 카드의 [변경 입력]으로 들어오면 변경 입력 바에 포커스를 둔다. 그 밖의 경로(작성의 [확정], 홈 [열기])에서는 제목에 둔다.
- 변경 카드를 [적용]하면 바로 최소 변경으로 다시 만든다.
- **버튼**: 지금 할 일 하나만 Primary다.
  | 상태 | Primary | 그 밖 |
  |---|---|---|
  | 변경 없음 | 없음 | [CSV 받기] Secondary |
  | 변경 있음 | [다시 확정] | [변경 취소] Text(마지막 확정본의 배정과 요청으로 되돌림, 확인 없이 바로), [CSV 받기] Text |
- **끝난 근무표**(오늘이 근무표 뒤): 보기 전용. 변경 입력 카드와 칸 편집이 없고 [CSV 받기] Secondary만 둔다.
- **게스트 확정**: 게스트도 [확정]을 바로 할 수 있다. 확정하면 확정 근무표 화면 맨 위에 게스트 저장 안내 배너 "확정했어요. 이 브라우저에만 저장돼 있어요" + [Google로 로그인]을 보여 준다. 로그인 대화상자를 띄우지 않는다.

### 병동 설정
- 탭 [명단·필요 인원]: 맨 위에 "기본" 영역(병동 이름, 근무표 주기 select: 한 달(1일~말일) / 1주 / 2주 / 4주)을 두고, 그 아래 명단 표와 필요 인원 폼을 둔다.
- 명단 표 위에 "바꾼 내용은 바로 저장돼요" 한 줄을 둔다(저장 버튼이 없다는 것을 알린다).
- 명단 표 맨 아래에 입력 줄(이름, 연차, 나이트 전담, [추가] Text)을 둔다. 명단이 비어 있어도 이 줄은 보인다.
  - 이름이나 연차 칸에서 Enter를 누르거나 [추가]를 누르면 한 명이 더해지고, 입력 줄이 비워진 채 이름 칸으로 포커스가 돌아간다.
  - 이름이 비었거나 같은 이름이 있으면, 연차가 숫자가 아니면 더하지 않고 그 칸에 오류를 보인다.
  - 활성 간호사가 40명이면 입력 줄 대신 "간호사는 최대 40명까지 넣을 수 있어요."를 둔다.
- 필요 인원 폼: 근무조(D/E/N) × 평일/주말·공휴일 6칸. 칸마다 숫자 하나 + "명"이고, 정확히 그 인원을 뜻한다.
  - 제목 아래 설명 한 줄: "하루에 그 근무조에 들어갈 간호사 수예요. 근무표는 날마다 이 인원을 그대로 맞춰요."
  - 표 맨 아래 "하루" 줄에 평일·주말·공휴일 각각 "8명 근무 · 7명 쉼"(활성 명단 기준)을 보인다.
  - 하루 근무 인원이 활성 명단 이상이면 "평일에 하루 15명이 일해야 해서 쉴 사람이 없어요. 명단은 15명이에요."를 오류로 보인다.
  - 숫자가 아니면 그 칸을 오류로 두고 "인원은 숫자로 적어 주세요."를 보인다.
  - 예전에 범위로 저장한 값은 "3~4"로 보이고, 고치면 숫자 하나로 바뀐다.
- 탭 [병동 규칙]: 자연어 입력 바 + 규칙 카드. 입력 바 아래에 실제 말투 예시 2~3개를 Text 버튼으로 두고, 누르면 입력 바에 채운다.
- 처음 설정을 마친 뒤에만 쓰므로 [첫 근무표 만들기]를 두지 않는다.
- 근무표 주기를 바꾸면 "다음에 만드는 근무표부터 적용돼요. 최소 휴무 일수 같은 규칙 값을 다시 확인하세요"를 주의 배너로 보여 준다. 근무표가 아직 없으면(처음 설정) 보이지 않는다.

## 컴포넌트
모서리는 크기에 따라 다르게 한다: 셀 `rounded-xs`(2px) · 배지 `rounded-sm`(4px) · 버튼·입력 `rounded-md`(6px) · 카드 `rounded-lg`(8px).

### 카드
```
rounded-lg bg-white border border-[#E2E2DC] px-[18px] py-4
```
- 적용 대기 카드: 테두리만 `border-[#C9C9C1]`로 한 단계 진하게
- 해 없음 패널: `border-[#E8B4AE]`
- 카드에 왼쪽 굵은 테두리 강조나 그림자를 넣지 않는다

### 버튼
```
공통:      inline-flex items-center gap-2 h-10 px-4 rounded-md text-sm font-medium transition-colors duration-[120ms]
Primary:   bg-[#155E75] text-white border border-[#155E75] hover:bg-[#0E4A5C]
Secondary: bg-white text-[#1B1B18] border border-[#C9C9C1] hover:bg-[#EFEFEB]
Text:      px-2 text-[#3D3D38] hover:bg-[#EFEFEB] hover:text-[#1B1B18]
Danger:    px-2 text-[#B42318]  (삭제 등)
Disabled:  bg-[#EFEFEB] text-[#9A9A91] border border-[#E2E2DC] cursor-not-allowed
카드 안:   h-8 text-[13px]
랜딩:      h-11 text-[15px] px-[18px]
```
한 영역에 Primary는 하나만 둔다.
- **배치**: Primary는 영역의 오른쪽 끝에 둔다. Danger는 Primary와 떨어뜨려 왼쪽에 두거나 메뉴 안에 넣는다. 바로 옆에 붙이지 않는다.
- **레이블**: 눌렀을 때 일어나는 일을 동사로 쓴다("근무표 만들기", "적용", "12월 근무표 만들기"). "확인", "OK"처럼 결과를 알 수 없는 레이블은 쓰지 않는다.

### 입력 필드
```
h-10 rounded-md bg-white border border-[#8A8A80] px-3 text-sm text-[#1B1B18] placeholder:text-[#707068]
focus:outline-2 focus:outline-[#155E75] focus:-outline-offset-1 focus:border-[#155E75]
```
- 레이블은 항상 `<label>`로 위에 둔다: `text-xs font-medium text-[#3D3D38]`
- 자연어 입력 바(규칙·요청·월중 변경 공통): 입력 `flex-1` + 오른쪽 Primary 버튼, `gap-2`. placeholder는 "예: 나이트 다음 날은 무조건 쉬게"처럼 실제 말투 예시

### 배지
```
inline-flex items-center h-[22px] px-2 rounded-sm text-xs font-semibold
반드시:    bg-[#1B1B18] text-white          (hard)
가능하면:  bg-white text-[#3D3D38] border border-[#C9C9C1]   (soft)
검증됨:    bg-[#E6F2EA] text-[#1E6B3F]
적용 대기: bg-[#FDF0DC] text-[#7A4506]
근무표 없음: bg-[#FBE9E7] text-[#9F1F14]   (해 없음)
작성 중:   가능하면과 같음
확정:      검증됨과 같음
운영 중:   bg-[#E3F0F3] text-[#155E75]
이번 근무표에서 꺼짐: 적용 대기와 같음
제외:      bg-[#EFEFEB] text-[#66665E]   (비활성 간호사)
```

### 반드시/가능하면 토글
화면에는 `hard`/`soft`를 쓰지 않는다. 버튼 글자는 "반드시" / "가능하면"이다.
```
컨테이너: inline-flex rounded-md border border-[#C9C9C1] overflow-hidden
버튼:     h-7 px-3 text-xs font-medium bg-white text-[#66665E]
선택됨:   aria-pressed="true" → bg-[#1B1B18] text-white
```

### 규칙·요청 카드
위에서부터 템플릿 이름(`text-[13px] font-semibold`) + 반드시/가능하면 토글, 원문 인용(“…”, `text-sm text-[#1B1B18]`), 해석 결과(`text-xs text-[#3D3D38] bg-[#F6F6F3] rounded-sm px-2.5 py-2`), 상태 배지 + 버튼(적용됨이면 수정·삭제, 대기면 삭제·적용).
- **해석 결과는 사람이 읽는 문장**으로 쓴다. 내부 id(`n01`), 근무 코드만 있는 표기(`N 뒤 O 1일`, `· O`)를 그대로 보여 주지 않는다. 날짜와 숫자만 mono로 둔다.
  - 예: "이영희 · 11/15~11/17 · 휴무", "나이트 다음 날은 휴무 1일", "박민수 · 주말·공휴일 · 나이트 피하기"
- **카드 순서는 바뀌지 않는다.** 적용해도 카드는 제자리에서 배지와 버튼만 바뀐다. 새 카드는 목록 맨 위에 붙는다.

### 제안 카드
제목 + `검증됨` 배지, 설명 한 줄, 검증 결과(`text-xs text-[#66665E]`, 예: "이렇게 바꾸면 근무표를 만들 수 있어요 · 희망 반영 14/16"), 오른쪽 아래 [무시] Text + [수락] Primary. 재풀이로 검증되지 않은 제안은 보여주지 않는다.

### 스테퍼
- 위치: 처음 설정·근무표 작성 화면의 제목 아래. 상단 바에는 두지 않는다. 확정 근무표에는 두지 않는다.
- 이미 지난 단계는 `<button>`으로 눌러 돌아갈 수 있다. 아직 오지 않은 단계는 비활성이다.
- 완료: `size-[22px] rounded-full bg-[#E3F0F3] text-[#155E75]` 안에 체크 SVG, 레이블 `text-[#3D3D38]`
- 현재: `bg-[#155E75] text-white` 숫자(mono), 레이블 `font-semibold text-[#1B1B18]`, `aria-current="step"`
- 단계 사이: `w-6 h-px bg-[#C9C9C1]`

### 근무 셀
```
relative w-[30px] h-7 rounded-xs inline-flex items-center justify-center font-mono text-[13px] font-semibold border border-transparent
+ 근무 코드 색상
고정:      오른쪽 위 자물쇠 SVG (absolute top-px right-px size-[9px])
변경됨:    shadow-[inset_0_0_0_2px_#D97706]
선택·편집: outline-2 outline-[#155E75] outline-offset-1
```
- 셀은 `<button>`으로 만들고 `aria-label="{이름} {M}월 {D}일 {코드}"`. 기간이 월 경계를 넘을 수 있으므로 월을 날짜마다 계산한다.
- 행 그리드: `grid-cols-[150px_44px_repeat(N,30px)_repeat(4,34px)_repeat(2,44px)] gap-x-0.5`, N은 기간 길이(7~31), 행 간격 2px
- 표 하단에 날짜별 D/E/N 합계 행, 오른쪽에 개인별 D/E/N/O 합계 열과 누적 부담 열 2개(최근 4주 N, 주말)
- 날짜 헤더가 달의 1일이면 `M/1`로 월을 함께 쓴다.
- **지난 날짜**: 운영 중인 기간에서 오늘 이전 칸은 고정 자물쇠를 표시하고 눌러도 편집되지 않는다. 오늘 열 머리에는 `border-b-2 border-[#155E75]` 밑줄을 긋는다.

### 반복 사용 컴포넌트
- **꺼진 규칙·요청 카드**
  - 원문과 해석 결과를 보조 색(`text-[#66665E]`)으로 낮춘다. 읽을 수 있어야 하므로 비활성 컨트롤 색은 쓰지 않는다.
  - `이번 근무표에서 꺼짐` 배지와 [다시 켜기] Text 버튼을 둔다.
  - 병동 규칙 탭에서는 꺼짐이 보이지 않는다. 꺼짐은 그 근무표에만 있다.
- **제외된 간호사**(휴직·퇴사)
  - 명단 표에서 이름을 `text-[#66665E]`로 하고 `제외` 배지를 붙인다.
  - 기본으로 접어 두고 "제외된 간호사 1명 보기" Text 버튼으로 펼친다.
  - 행의 동작은 [근무표에서 빼기] / [다시 넣기]다. 빼도 지난 근무표와 통계에는 남는다고 버튼 근처에 한 줄로 쓴다.
  - [삭제]는 한 번도 근무표에 들어간 적 없는 간호사에게만 보이고, 행 끝 메뉴 안에 둔다. [근무표에서 빼기]와 나란히 두지 않는다.
- **지난 근무 마지막 며칠 표**
  - 근무 셀 그리드를 재사용한다. 열은 지난 근무표 마지막 날들이고, 표 위에 "지난 근무표에서 가져왔어요. 나이트 다음 휴무 같은 규칙이 근무표 사이에서도 지켜지게 써요" 보조 텍스트를 둔다.
  - 셀은 `<div>`로 만들고 편집하지 않는다.
  - 첫 근무표처럼 지난 확정 근무표가 없으면 접힌 붙여넣기 입력을 쓴다(근무표 작성 ① 요청의 준비 요약).
- **최근 4주 부담**
  - 그리드 오른쪽 열과 통계 표 열 이름은 "최근 4주 나이트", "최근 4주 주말"이다. mono 숫자.
  - 최근 4주 기록이 하나도 없으면(첫 근무표) 이 열들을 그리지 않는다.
  - 요약 지표 아래에 한 줄로 "최근 4주 나이트가 많았던 3명은 이번 근무표에서 나이트를 줄였어요"처럼 근거를 쓴다. 숫자가 없으면 쓰지 않는다.
- **배너**: 지난 근무 변경, 게스트 저장 안내, 저장 실패, 근무표 주기 변경은 모두 기존 주의 배너(`bg-[#FDF0DC] border-[#F1D3A8] text-[#7A4506]`) 하나로 쓴다. 배너에 버튼은 최대 하나다.
- **저장 상태**: 상단 바 오른쪽, 계정 왼쪽에 `text-xs text-[#66665E]`로 둔다.
  - 게스트: "이 브라우저에만 저장"
  - 로그인: "저장됨 14:32"(mono 시각)
  - 실패: `text-[#B42318]` "저장 실패" + [다시 시도] Text
- **계정**
  - 로그인 전: [Google로 로그인] Secondary
  - 로그인 후: 이메일(`text-xs`) + 메뉴 버튼. 메뉴 항목은 [로그아웃], [내 병동 데이터 삭제] Danger
- **대화상자**
  - 서버 우선 안내, 데이터 삭제 확인, 게스트 입력 지우기 확인에만 쓴다. 로그인을 요구하는 대화상자는 두지 않는다(로그인은 권유만 한다).
  - 배경 `fixed inset-0 bg-[#1B1B18]/40`, 본문은 카드 스타일 `w-full max-w-[440px]`. blur와 그림자를 쓰지 않는다.
  - 제목(섹션 제목 스타일), 본문 한두 줄, 오른쪽 아래 버튼. Primary는 하나다.
  - 데이터 삭제는 2단계다. 첫 대화상자에서 [계속], 두 번째에서 병동 이름을 입력하고 [삭제](Danger 스타일을 Primary 자리에 둔다).
  - `role="dialog"`, `aria-modal="true"`, Esc로 닫고, 열릴 때 첫 버튼에 포커스를 둔다.

### 요약 지표
카드 안 가로 배치, 칸마다 `px-5 py-3.5 border-r border-[#E2E2DC]`. 레이블 `text-xs font-medium text-[#66665E]`, 값 `font-mono text-xl font-semibold text-[#1B1B18]`. "못 지킨 규칙" 값만 `text-[#A15C07]`.
- 칸: "결과"(`규칙을 모두 지켰어요` / `근무표 없음` 배지), "희망 반영"(예: 9/9, 아래에 "희망·기피 요청이 걸린 날 중 지킨 날" 보조 한 줄), "못 지킨 규칙"('가능하면' 규칙을 못 지킨 횟수)

## 상호작용 상태
버튼, 탭, 근무 셀, 토글은 아래 상태를 모두 가진다. 같은 종류의 컨트롤은 화면이 달라도 똑같이 동작한다.

| 상태 | 규칙 |
|---|---|
| 기본 | 버튼은 버튼답게 보인다. 레이블만 봐도 결과를 알 수 있다 |
| hover | 색만 바꾼다(`transition-colors duration-[120ms]`) |
| 눌림 | `active:` 상태에서 hover보다 한 단계 진하게 한다(Primary `active:bg-[#0B3F4E]`, Secondary·Text `active:bg-[#E2E2DC]`) |
| 포커스 | 키보드 포커스에만 `focus-visible:outline-2 focus-visible:outline-[#155E75] focus-visible:outline-offset-2`. 포커스 표시를 없애지 않는다 |
| 비활성 | 숨기지 않고 비활성 스타일로 둔다. **왜 못 누르는지** 버튼 옆이나 아래에 한 줄로 쓴다. 예: "필요 인원을 입력하면 다음으로 넘어갈 수 있어요" |
| 진행 중 | 레이블을 "만드는 중…", "읽는 중…", "저장 중…"으로 바꾸고 스피너 하나만 둔다. 진행 중에는 버튼을 비활성으로 해서 두 번 보내지 않게 한다 |
| 성공 | 결과가 놓일 자리에 보여 준다(카드 배지가 `적용됨`으로 바뀜, 근무표가 갱신됨, 저장 상태가 "저장됨 14:32"로 바뀜). 토스트는 쓰지 않는다 |
| 실패 | 버튼을 다시 누를 수 있는 상태로 되돌리고, 바로 아래에 무엇이 잘못됐고 무엇을 하면 되는지 쓴다 |
| 선택됨 | 채운 스타일(`bg-[#1B1B18] text-white`)과 `aria-pressed="true"`, 탭은 `aria-current="page"` |

## 피드백과 오류
- **결과는 그 자리에서**: 동작의 결과는 누른 버튼 가까이에 보여 준다. 화면 위쪽 전역 알림으로 보내지 않는다. 예외는 상단 바의 저장 상태 하나다.
- **기다림**: 2초를 넘을 수 있는 작업(생성, 해석, 제안 검증)은 진행 중 상태를 보여 준다. 진행률을 알 수 없으므로 진행 막대는 쓰지 않는다.
- **오류 문구**: "무엇이 일어났는지 + 무엇을 하면 되는지" 두 부분으로 쓴다. 예: "해석하지 못했어요. 날짜를 '15~17일'처럼 다시 적어 주세요." 오류 코드나 영어 원문을 그대로 보여 주지 않는다.
- **되돌릴 수 있는 동작은 즉시**: 카드 삭제, 이번 근무표에서만 끄기, 근무표에서 빼기는 확인 없이 바로 하고, 그 자리에 되돌리기(다시 켜기, 다시 넣기)를 둔다.
- **되돌릴 수 없는 동작만 확인**: 내 병동 데이터 삭제, 게스트 입력을 지우고 새로 시작하기는 대화상자로 확인한다. 대화상자의 버튼은 두 개까지다.
- **예방**: 틀릴 수 있는 입력은 고르게 한다(근무표 주기 select, 공휴일 달력, 나이트 전담 체크박스). 자유 입력은 자연어 입력 바뿐이고, 그 결과는 항상 카드로 확인받는다.

## 문구
- **읽는 사람은 수간호사다.** 개발과 솔버 용어를 화면에 쓰지 않는다. 엑셀로 근무표를 짜 온 사람이 처음 보고 이해할 말로 쓴다. 코드와 문서 안의 이름(`period`, `carry_over`, `hard` 등)은 그대로 두고 화면 문구만 바꾼다.
- **말투**: 해요체로 짧게 쓴다. 한 문장에 한 가지만 말한다.
- **같은 것은 같은 말로**: 화면마다 용어를 바꾸지 않는다.
- **숫자에는 뜻을 붙인다**: 표의 열 이름이나 지표 레이블만 보고 무엇을 센 숫자인지 알 수 있어야 한다. 약어(`4주 N`, `N전담`)를 쓰지 않는다.

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| 근무표, "11월 근무표", "11/2~11/15 근무표" | 기간, 이번 기간, 다음 기간, 이달 | 병동의 근무표 주기 하나(1주~한 달) |
| 다음 근무표 | 다음 기간 | 아직 시작하지 않은 근무표 |
| 근무표 주기: 한 달(1일~말일) / 1주 / 2주 / 4주 | 기간 단위, 달력 월 | 병동이 근무표를 새로 짜는 간격 |
| 병동 규칙 | 설정, 제약 | 근무표가 바뀌어도 유지되는 규칙. 필요 인원은 따로 센다 |
| 요청 | 이달 요청, 희망 | 이 근무표에만 적용되는 휴가·희망·기피 |
| 지난 근무 마지막 며칠 | 이월 근무, 전월 근무 | 지난 근무표 끝부분의 근무 |
| 작성 중 / 확정 / 운영 중 | 초안, 저장, 완료 | 근무표의 상태. 운영 중은 오늘이 속한 확정 근무표 |
| 반드시 / 가능하면 | hard / soft, 필수 / 선택 | 규칙을 지키는 정도 |
| 못 지킨 규칙 | soft 위반 | '가능하면' 규칙을 지키지 못한 횟수 |
| 근무표 만들기 / 다시 만들기 | 생성, 풀이, 재풀이, 다시 풀어요 | 솔버를 돌리는 것 |
| 규칙을 모두 지켰어요 / 근무표 없음 | 해 있음 / 해 없음 | 생성 결과 |
| 규칙 만들기 / 요청 만들기 | 해석 | 자연어를 카드로 바꾸는 버튼 |
| 표로 만들기 | 변환, 반영 | 붙여넣은 지난 근무를 표로 바꾸는 버튼 |
| 적용 | 추가, 저장 | 규칙·요청 카드를 반영하는 것 |
| 수락 | 적용 | 검증된 완화 제안을 반영하는 것 |
| 근무표에서 빼기 / 제외 / 다시 넣기 | 비활성, 비활성으로, 활성, 삭제, 퇴사 | 휴직·퇴사한 간호사를 새 근무표에서만 빼는 것 |
| 간호사 15명 | 활성 15명 | 새 근무표에 들어가는 간호사 수 |
| 나이트 전담 | N전담 | N과 휴무만 배정하는 간호사 |
| 휴무 | O, 오프(문장 안) | 근무 셀 글자는 O를 그대로 쓴다 |
| 최근 4주 나이트 / 최근 4주 주말 | 4주 N, 4주 주말, 누적 부담 | 직전 4주의 확정 근무 수 |
| 평균보다 많은 근무일 (예: +2일, −1일) | 평균 대비 편차, -0.40 | 개인 근무일 수와 평균의 차이. 정수 일로 반올림 |

- **빈 상태**: 비어 있는 영역에는 무엇을 하면 채워지는지 한 줄과 그 동작 버튼을 둔다. 예: 지난 근무표 표가 비면 "확정한 근무표가 여기에 쌓여요".
- **내부 값 노출 금지**: 간호사 id(`n01`), 제약 type 이름, 영어 오류 원문을 화면에 보여 주지 않는다.

## 접근성
- **대비** (WCAG 2.2 AA): 본문 텍스트 4.5:1, 큰 텍스트와 컨트롤 경계 3:1 이상. 이 가이드의 색 조합을 계산한 결과는 아래와 같다.
  - 통과: 주 텍스트·본문·보조(`#66665E` 5.8:1), 강조(`#155E75` 7.3:1), 시맨틱 배지 전부(5.6~7.0:1), 근무 코드 전부(4.6~12.9:1)
  - 정보 텍스트에 쓰지 않음: 비활성 컨트롤 색 `#9A9A91`(2.8:1)
  - 이번에 바꿈: placeholder `#8A8A80` → `#707068`(5.0:1), 입력 테두리 `#C9C9C1`(1.7:1) → `#8A8A80`(3.5:1)
- **색만으로 구분하지 않는다**: 근무 코드는 글자, 상태는 배지 글자, 변경된 칸은 테두리, 고정은 자물쇠로 함께 표시한다.
- **키보드**
  - 모든 동작은 Tab과 Enter/Space로 할 수 있다.
  - 스테퍼 단계를 옮기면 새 단계의 제목(`h2`, `tabIndex={-1}`)으로 포커스를 옮긴다.
  - 대화상자를 닫으면 연 버튼으로 포커스를 되돌린다.
- **상태 알림**: 진행 중, 결과, 오류 문구는 `role="status"`(오류는 `role="alert"`) 안에 두어 스크린 리더가 읽게 한다.
- **레이블**: 아이콘만 있는 버튼은 `aria-label`, 입력은 `<label>`을 쓴다. placeholder를 레이블 대신 쓰지 않는다.

## 레이아웃
- 전체 너비: `max-w-[1360px] mx-auto px-8`
- 정렬: 좌측 정렬 기본. 중앙 정렬 히어로 금지
- 간격: 카드 사이 `gap-4`~`gap-5`, 앱 화면 섹션 사이 `gap-5`, 카드 안 `gap-2.5`~`gap-3.5`
- 묶음: 관련된 입력과 버튼은 같은 카드 안에 붙여 둔다. 서로 다른 일은 카드를 나눈다. 카드 안의 간격은 카드 사이 간격보다 항상 좁다
- 위계: 화면마다 페이지 제목은 하나다. 화면을 위에서부터 읽으면 "지금 상태 → 할 일 → 결과" 순서가 되게 놓는다
- 앱 상단 바: `bg-white border-b border-[#E2E2DC]`, 왼쪽 앱 이름 + 병동 이름·근무표 주기("한 달 단위"), 오른쪽 저장 상태 + 계정. 스테퍼는 두지 않는다
- 탭 줄: 상단 바 바로 아래 `bg-white border-b border-[#E2E2DC]`, [근무표] [병동 설정] (+ 게스트면 오른쪽 [시작 화면]). 시작 화면에서는 숨기고, 처음 설정에서는 [시작 화면]만 둔다
- 근무표·통계 표는 `overflow-x-auto` 상자 안에 둔다. 표를 줄이거나 셀을 30px보다 작게 만들지 않는다
- 랜딩 페이지: 섹션 `py-[72px] border-t border-[#E2E2DC]`, 첫 화면은 좌측 텍스트 + 우측 실제 제품 화면 조각(규칙 카드, 근무표 일부). 장식 이미지나 근거 없는 수치·후기를 넣지 않는다. 문구는 앱과 같은 "문구" 표를 따르고, 기술 설명은 맨 아래 "만든 방식" 섹션 하나에만 둔다(PRD 핵심 기능 9)
