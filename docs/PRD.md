# PRD: 간호사 근무표 (LLM + CP-SAT)

## 목표
수간호사가 말로 설명한 규칙과 요청으로 한 달 근무표를 만들고, 막히는 이유와 변경 영향을 설명받게 한다.
판매용 제품이 아니라 LLM 활용 빌드 역량을 보여주는 포트폴리오 프로토타입이다. 계산은 CP-SAT 솔버가 하고, LLM은 번역과 설명만 맡는다.

## 사용자
- **수간호사 1명.** 예: 내과 병동, 로테이션 인원 15명, 3교대.
- 지금은 매달 엑셀과 머릿속 규칙으로 며칠씩 걸려서 짠다.
- 엑셀은 능숙하지만 설정 화면은 싫어하고, 말로 설명하는 게 편하다.
- 수간호사 본인(상근 Day)은 로테이션 명단에 넣지 않는다.

| 페인 포인트 | 해결 기능 |
|---|---|
| 규칙이 머릿속에만 있다 | 자연어 → 규칙 카드 |
| 요청이 다 안 들어가는데 어디서 막히는지 모른다 | 충돌 설명과, 재풀이로 검증된 완화 제안 |
| 확정 후 병가가 생기면 전체를 다시 짠다 | 최소 변경 재스케줄 |
| "왜 나만 주말이 많아요?"에 근거를 대기 어렵다 | 개인별 통계 |

## 사용자 저니 (한 달 사이클)
화면은 두 개다.
- **랜딩**(`/`): 소개 페이지. [데모 시작]을 누르면 앱으로 간다.
- **앱**(`/app`): 스테퍼 4개(① 병동 → ② 규칙 → ③ 이달 요청 → ④ 근무표). ⑤~⑧은 ④ 화면 안에서 일어난다.

0. **시작 방법 선택**: `/app`에 들어올 때마다 고른다.
   - [샘플로 체험하기]: 샘플 병동(15명)을 불러와 ① 병동에서 시작한다.
   - [내 데이터로 시작하기]: 빈 상태로 ① 병동에서 시작한다.
   - [이어서 하기]: 저장된 입력이 있을 때만 보인다. 마지막 단계로 돌아간다.
   - 저장된 입력이 있는데 샘플이나 새로 시작을 고르면, 기존 입력을 지운다는 확인을 받는다.
1. **병동 준비**
   - 대상 월을 선택한다(기본값은 다음 달).
   - 엑셀 명단(이름, 연차, 나이트 전담)을 붙여넣거나 CSV 파일로 올리거나 샘플을 불러온다. 붙여넣거나 올리면 열 매핑을 거쳐 편집 가능한 표가 된다. CSV는 UTF-8과 엑셀 기본 저장 형식(CP949)을 읽는다.
   - 입력이 있는 상태에서 샘플을 불러오면 덮어쓰기 확인을 받는다.
   - 근무조별 필요 인원(평일 / 주말·공휴일)을 입력하고 공휴일 날짜를 체크한다.
2. **병동 규칙**: "나이트 다음 날은 무조건 쉬게"를 입력하면 규칙 카드가 생긴다.
   - 카드에는 원문, hard/soft 토글, 적용/수정/삭제 버튼이 있다.
   - 입력이 모호하면 되묻고, 지원하지 않는 규칙이면 그렇다고 안내한다.
3. **이달 요청**: "이영희 15~17일 휴가"를 입력하면 요청 카드가 생긴다. 전월 마지막 주 근무 붙여넣기는 선택이다.
4. **생성**: 근무표, 요약(희망 반영 수, soft 위반), 개인별 통계를 보여준다.
5. **해가 없을 때**: 충돌 설명과, 재풀이로 검증된 완화 제안을 보여준다. 제안이 없거나 LLM이 실패하면 [이번 달만 끄기]를 쓴다.
6. **조정**: 칸을 수정하고 🔒 고정한 뒤 재풀이한다.
7. **확정**: CSV를 다운로드한다.
8. **월중 변경**: "최지훈 이번 주 병가"를 입력하면 최소 변경으로 재스케줄하고, 변경된 칸을 하이라이트한다.

## 핵심 기능
1. **자연어 → 제약 카드.** 템플릿 12개 중에서 고르고 파라미터를 채운다. 사람이 [적용]해야 반영된다.
   - 기본값 hard
     1. 일일 최소/최대 인원
     2. 금지 순서
     3. 최대 연속 근무
     4. 최대 연속 나이트
     5. 최소 오프 일수
     6. N-OFF
     7. 숙련도 믹스
     8. 휴가 (항상 hard)
     9. 고정 배정 (항상 hard)
   - 기본값 soft
     10. 희망 / 기피 근무
     11. 나이트 공정성
     12. 주말·공휴일 공정성
2. **CP-SAT 근무표 생성.**
   - 기간은 달력 월(28~31일)이다.
   - 주말은 토·일과 체크한 공휴일이다.
   - 나이트 전담은 N/O만 배정하고 나이트 공정성 계산에서 제외한다.
   - 전월 이월 근무를 반영한다.
3. **해가 없을 때 원인 설명.** 충돌하는 제약을 찾아 설명하고, 재풀이로 검증한 완화 제안만 보여준다.
4. **최소 변경 재스케줄.** 수동 고정과 월중 변경을 반영하고, 변경 칸을 표시한다.
5. **개인별 통계와 CSV.**
   - 통계: D/E/N/O 개수, 주말·공휴일 근무 수, 최대 연속 근무, 희망 반영률, 평균 대비 편차
   - CSV: 행은 간호사, 열은 이름·연차·1~말일·합계. 첫 행에 요일, 하단에 날짜별 D/E/N 합계. UTF-8 BOM.
6. **LLM 번역 정확도 eval.** 수간호사 말투 40개 내외의 데이터셋으로 측정한다.
7. **랜딩페이지(`/`).** 포트폴리오 방문자에게 프로젝트를 소개한다. 정적 페이지이고 API를 호출하지 않는다.
   - 첫 화면: 좌측 텍스트(한 줄 가치 제안 + [데모 시작] → `/app`), 우측 실제 제품 화면 조각(규칙 카드, 근무표 일부). 중앙 정렬 히어로와 장식 이미지는 쓰지 않는다(UI_GUIDE)
   - 문제: 수간호사 페인 포인트 4개
   - 동작 방식: 말로 규칙 입력 → 솔버가 생성 → 막히면 이유와 해결책 제시
   - 데모 GIF: 배포 체크포인트에서 녹화해 넣는다. 그전까지는 자리표시
   - 설계 요약: LLM은 번역과 설명, CP-SAT는 계산, LLM 출력 검증 장치, eval 결과
   - GitHub 링크

## MVP 제외 사항
- 인증, 결제, DB, 공유 링크
- 다중 병동, 간호사 본인용 화면, 수간호사 본인 근무
- 인쇄용 뷰, JSON 내보내기/불러오기
- LLM 요약 문장, 공정성 Q&A, 가중치 UI

- 자체 솔버, 모델 비교 eval

## 데모 저니 (최종 수용 기준)
1. 랜딩에서 [데모 시작]을 누르고, 15명 명단을 붙여넣은 뒤 공휴일 1일을 체크한다.
2. 규칙 3개를 입력한다(나이트 다음 날 휴무, 나이트 3연속 상한, 조마다 3년차 이상 1명).
3. 요청 2개를 입력한다(휴가는 hard, 주말 오프 희망은 soft).
4. 생성 → 근무표, 요약, 통계.
5. 휴가 2건을 추가하면 해가 없다고 나오고, 설명과 검증된 제안이 뜬다. 수락하면 해결된다.
6. 칸을 🔒 고정한 뒤 재풀이한다.
7. 확정하고 CSV를 받는다.
8. 병가를 입력하면 최소 변경으로 재스케줄된다.
